# Student folder template

1. Copy this folder and rename it with the student's ID, e.g. `people/students/msc-1405-ahmadi/`
2. Replace `photo.svg` with a square `photo.jpg` (≥ 400 × 400 px).
3. Add one row to `data/team.csv`:

```
msc-1405-ahmadi,Ali Ahmadi,msc,,MSc Student,people/students/msc-1405-ahmadi/photo.jpg,ali@example.com,,Thesis title here,,https://scholar.google.com/...,,https://orcid.org/...,,https://www.linkedin.com/in/...,https://github.com/...,
```

`category` = `phd`, `msc`, `bsc` or `alumni`.
